8/26 태조산 합주 캘린더 초안

[작업 내용]
- Vite + React + TypeScript로 태조산 합주 캘린더 홈페이지 생성
- 기수/이름 로그인 (비밀번호 없음, 세션 유지)
- 월간 캘린더에서 날짜 넘기기 / 합주 등록·수정·삭제
- 로그인·등록·수정·삭제 활동 로그 기록
- 데이터는 브라우저 localStorage에 저장 (인터넷 공유는 다음 단계)

[사용 방법]
1. npm install
2. npm run dev
3. 브라우저에서 기수·이름 입력 후 합주 일정 사용

[다음 단계 후보]
- 멤버끼리 실시간 공유를 위한 서버/DB 연동
- 배포(Vercel 등)로 인터넷 접속
